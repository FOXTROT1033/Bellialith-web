Privacy Policy

Last updated: August 21, 2026

1. Introduction

Bellialith is a Discord bot focused on character collecting, rolls, progression, rewards, inventory and an in-server economy.

This Privacy Policy explains what information Bellialith processes, where that information is used, and how it is handled when you interact with the bot.

2. Information Stored

Bellialith stores information required to provide its gameplay and progression systems. Persistent gameplay data is stored using SQLite.

Depending on your use of Bellialith, the stored gameplay information may include:

  • Your Discord User ID
  • Coins
  • Experience points (XP)
  • Rolls and remaining rolls
  • Collected characters
  • Inventory items
  • Daily reward-related progression
  • Other gameplay progression required by Bellialith's systems

Bellialith does not use your Discord username as the persistent identifier for your gameplay database record. The bot primarily associates gameplay data with your Discord User ID.

3. Profile, Collection and Inventory Data

Bellialith's profile system can display gameplay information such as level, XP, coins, rolls, remaining rolls and daily or extra progression.

Characters are added to a user's collection after the user obtains a character through Bellialith's roll and claim systems.

Inventory data represents items obtained through Bellialith's shop and related gameplay systems.

4. Character Data

Bellialith maintains a static character catalog separately from user gameplay data. Character information is stored in a JSON file and is used to provide the available character catalog.

The character catalog itself is not a personal user profile and does not represent a user's collected characters. A user's collection is stored separately as gameplay data.

5. Server and Channel Information

Bellialith processes Discord server information required to operate within a server.

Server-specific information may be used for features such as moderation logging and server-specific bot behavior.

Channel information may appear in moderation logs when an event occurs in a Discord channel. Channel information used by moderation logs is not part of the user's persistent gameplay profile.

6. Moderation Logs

Bellialith includes a moderation logging system that operates through a dedicated Discord moderation-log channel.

Depending on the event, moderation logs may contain information such as:

  • Discord User ID
  • Discord username or display name
  • Server name
  • Channel information
  • Message content when a message is deleted or edited
  • Information about member joins and leaves
  • Information about bans
  • Information about timeouts and timeout removals
  • Event timestamps

These moderation records are handled through Discord channels and are separate from Bellialith's persistent gameplay database.

7. How Information Is Used

Information processed by Bellialith is used to:

  • Provide Bellialith's gameplay systems
  • Preserve user progression between sessions
  • Manage characters and collections
  • Manage coins, XP and rolls
  • Manage inventory and shop-related items
  • Provide daily rewards
  • Operate server moderation logs
  • Respond to commands and interactions

8. Data Sharing

Bellialith does not sell user gameplay data.

Bellialith does not currently use additional external APIs or third-party data services for its gameplay systems beyond the Discord platform required to operate the bot.

Information appearing in Discord moderation channels is subject to Discord's own platform and data practices.

9. Data Retention and Deletion

Gameplay information may remain stored while it is required for Bellialith to provide its persistent gameplay systems.

Bellialith currently does not provide a self-service command or automated system for permanently deleting a user's stored gameplay data.

Because the current bot does not include an automated data-deletion system, no automatic deletion procedure is represented by this website.

If Bellialith introduces a formal data deletion process in the future, this Privacy Policy will be updated to describe that process.

10. Security

Bellialith uses a local SQLite database for persistent gameplay information and Discord channels for moderation logging.

No online service can guarantee absolute security. Reasonable measures should be taken to protect the bot's database, configuration and Discord environment from unauthorized access.

11. Changes to This Policy

Bellialith is an actively developed project. Its features, data practices and infrastructure may change over time.

This Privacy Policy may therefore be updated when Bellialith introduces new features, changes how information is handled, or adds new data-related functionality.
